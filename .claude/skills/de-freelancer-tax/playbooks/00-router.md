# Profile router - pick the playbook(s) first

Ask until you can place the user. One person can fall into several rows (e.g. employee + freelance side job + rental flat).

| Situation | Playbook |
| :--- | :--- |
| Small turnover, no VAT charged | kleinunternehmer.md |
| Catalog or similar profession (§ 18 EStG): consultant, engineer, designer, writer, teacher, translator, doctor, lawyer | freiberufler.md |
| Trading, e-commerce, craft, café, software product, agency without catalog status | gewerbetreibende.md |
| Employed and earns extra (side gig, trainer/instructor pay, honorary posts) | nebentaetigkeit-arbeitnehmer.md |
| Own GmbH/UG, managing director, dividends, holding | gmbh-ug.md |
| Rents out property | vermietung.md |
| Savings, ETFs, shares, crypto, selling private assets | kapital-krypto.md |
| Starting up | gruendung-checklist.md |
| Any: "when is what due?" | jahreskalender.md |

Mixed income: income types are added up (Summe der Einkünfte) and taxed together at the progressive tariff (§ 32a EStG), except capital income at the flat 25% (§ 32d). Losses in one type may offset gains in another (**Verlustausgleich**), subject to § 10d EStG.

Escalate to a Steuerberater: cross-border work or residence changes, holding structures, selling a business, inheritance/gifts, payroll for employees, disputes with the Finanzamt.
